## 📖 Overview

AURA is an AI-powered Decision Intelligence Platform that enables governments, energy companies, and policymakers to proactively monitor global energy supply chains, detect geopolitical risks, simulate disruption scenarios, optimize crude oil procurement, and support strategic decision-making.

Unlike conventional monitoring dashboards, AURA combines **Agentic AI**, **Geospatial Intelligence**, **Knowledge Graphs**, **Retrieval-Augmented Generation (RAG)**, and **Predictive Analytics** to transform fragmented global intelligence into actionable recommendations.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/AURA.git
cd AURA
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Start the backend

```bash
npm run server
```
